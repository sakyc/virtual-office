# Karyora — logo concept 01

Original vector mark: a modular K, with a separate upright and joined directional
arms. The direction is clean, approachable SaaS branding rather than a robot or
provider-specific AI identity. This is a concept for review, not a trademark or
domain-availability clearance. No application branding has been replaced.

## Files

- `brand-preview.png` / `.svg`: concept presentation; the small descriptive copy
  and optional tagline on the presentation are not part of the logo.
- `logo-primary.svg`: iris mark + ink wordmark, transparent background.
- `logo-dark.svg`: lilac mark + white wordmark, transparent; for dark backgrounds.
- `logo-monochrome.svg`: one-color ink version, transparent.
- `wordmark.svg`: wordmark only, transparent.
- `mark.svg`: symbol only, transparent.
- `app-icon.svg` / `app-icon-512.png`: white mark on iris rounded square.
- `favicon.svg` / `favicon-32.png`: simplified scalable browser icon.
- `logo-primary.png`: transparent 1968 × 456 export.

All lettering in the logo SVGs is outlined, with no font, script, external image
or network dependency. The presentation SVG uses live text for its annotations.
Wordmark lettering is based on locally installed Segoe UI Bold, converted to
outlines; no font file is bundled. Mark geometry is authored directly as SVG.
Raster previews were rendered locally using an existing bundled Sharp runtime;
no dependency was installed and no image-generation API was called.

## Palette and use

Iris `#6254F4`; Ink `#181B27`; Lilac `#B0A7FF`; White `#FFFFFF`.

Keep clear space at least the width of the symbol's upright. Use the symbol alone
for small surfaces; suggested minimum full-logo width is 140 px and symbol size
24 px (favicon is a dedicated 32 px export). Do not stretch, add shadows, rotate,
or use the dark-background wordmark on white. Recheck legibility at the intended
size before deployment. Color and typography are proposals pending owner review.
